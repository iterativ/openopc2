# Third-party license research for OpenOPC 2 0.2.0

Checked 2026-10-23. This note distinguishes a vendor's published terms from proof that those terms cover the exact file committed here. Repository file hashes identify the copies examined; the source links identify the rights holders' own statements.

| Repository file | Finding | Confidence / release action |
| --- | --- | --- |
| `lib/gbda_aut.dll` | Graybox's [archived product page](https://web.archive.org/web/20240920163619id_/http://gray-box.net/daawrapper.php?lang=en) expressly permits free use and redistribution of its OPC DA Auto Wrapper with products and says there are no license limitations. The repository DLL identifies itself as Graybox software, PE file version `1.2.8.508`, and type library `1.01` (SHA-256 `735500ac58a9cd1e6359094e8c0bb91e62f8f15677507db8aef2eab592dfc283`). | Product-page permission supports bundling the DLL, but it does **not** make the DLL MIT licensed. The old vendor domain currently serves unrelated content, so the archived original page is the durable source to cite. Preserve Graybox attribution and keep it outside the project's MIT grant. |
| `scripts/graybox_opc_automation_wrapper.py` | Its header says `makepy.py` generated it from the `gbda_aut.dll` type library on 2022-10-05. Graybox's [archived permission](https://web.archive.org/web/20240920163619id_/http://gray-box.net/daawrapper.php?lang=en) addresses its wrapper DLL and redistribution with products; it does not expressly address generated Python source. | Treat as Graybox-derived material outside the project's MIT grant unless the generated source's rights are confirmed independently. |
| `lib/x64/OPC Core Components Redistributable (x64).msi` | The MSI identifies OPC Foundation as author, records `3.0.0.1` in its keywords, and has a 2019 last-saved timestamp (SHA-256 `d3ba2f2614f698f86889d88cd7174b761e5ed5f3898d03e99d1ac3b7414140cd`). OPC Foundation's [current download page](https://opcfoundation.org/developer-tools/samples-and-tools-classic/core-components/) says the Core Components package is now under the [OPC MIT license](https://opcfoundation.org/license/mit.html), but that page lists a newer 3.1.4.132 release dated 2026-07-06. Its [2017 redistributables agreement](https://opcfoundation.org/license/redistributables/1.3/) permits distribution with a program only under conditions, including significant primary functionality and downstream terms, and restricts publishing the deliverable alone. | The current MIT statement cannot yet be tied to this exact older MSI. Inspect the MSI's embedded license or replace it with the current vendor download before describing this copy as MIT licensed. Until then, keep it outside the project's MIT grant and do not imply unrestricted standalone redistribution. |
| `lib/api-ms-win-core-path-l1-1-0.dll` | The file's PE version resource identifies Microsoft Corporation, Windows operating system, and version `6.3.9600.16384` (SHA-256 `745c3aa5871af101b3b023a948fb0cc73904235085f011c9906a5804d5d71584`). Microsoft's [Windows 8.1 license terms](https://download.microsoft.com/Documents/UseTerms/Windows_8.1%20Pro_English_2e388b0d-3b05-4312-a480-be210adcf487.pdf) describe a license for installing and running Windows on one computer and transfer of the software with its license. Microsoft's [Visual C++ redistribution guidance](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files) illustrates that permissions for a separate class of Microsoft DLLs depend on a product license and distributable-file list; it does not grant rights to this Windows DLL. | No source or terms establishing a right to redistribute this **exact standalone Windows DLL** were found. It is not MIT licensed. Identify the package it came from and its redistribution terms, or remove it from any distributed repository/artifact. Do not infer permission from advice about other API-set DLLs or Visual C++ redistributables. |
| `doc/OpenOPC.pdf` | The [committed PDF](../../doc/OpenOPC.pdf) identifies itself as *OpenOPC Notes*, dated December 2008, with PDF author metadata `KR` (SHA-256 `7e93b9b22b7056f81cf754d29e92e954d38485e1cec0d9d1ee40f25d9bd0e0f9`). It contains no explicit license grant. The [OpenOPC project page](https://sourceforge.net/projects/openopc/) lists LGPLv2 for the project, but does not identify this document or establish that its project code license covers the PDF. | Copyright ownership and redistribution permission for this document are unverified. Keep it outside the project's MIT grant; obtain a grant or remove it from distributed material. |

The repository's [third-party notice](../../THIRD_PARTY_NOTICES.md) should state these file-specific findings without claiming that a license for a newer or similarly named product applies to an older copy. The checked 0.2.0 Python wheel and source distribution do not include the four bundled binary/PDF assets or the generated Graybox Python script, but the Git repository does contain them. This packaging observation does not establish a redistribution grant for the repository itself.
